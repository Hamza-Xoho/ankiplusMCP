# Student workflow acceptance

First release includes the complete approved product scope and verified required fixes. No source change or test result below implies release readiness.

## Required release evidence

- [ ] Reproducible CLI baseline in CI, plus real extraction/render and representative card-quality checks.
- [ ] Confirmed audit findings dispositioned and required fixes demonstrated.
- [ ] Independent maintainer/student quality review preserved on the chosen host.
- [ ] Interactive source-linked card-text review working in actual Claude Desktop under Pro.
- [ ] Actual companion adapter, exact proposal authorization and changed-collection conflict handling.
- [ ] Per-run permanent records with cumulative receipts, note/card distinction and rebuildable history index.
- [ ] Repeat sources and overlapping chapters handled without blind duplicate creation; ambiguity pending by default.
- [ ] Interruption after write reconciled without blindly resending.
- [ ] Nontechnical resumable installation, configurable workflow, guide and explicit preference changes.
- [ ] Real macOS setup and production isolated-profile Anki end-to-end test. Reported installer and stock-Cloze probes provide partial evidence only.
- [ ] Private-fixture and visual/card-quality acceptance resolved with the owner.
- [ ] Full documented checks and applicable hardened container smoke build pass.

## Current scope boundaries

Public publishing, merges, live collection mutation and exposing a local Anki endpoint are not authorized by implementation approval. Windows and alternative hosts are not supported merely because adapter/configuration unit tests pass. PDFCraft is optional; its integration cannot replace the agreed review UI without an explicit decision.

## Final pre-macOS pass

Local synthetic tests and the rehearsal prepare the Mac investigation only. See `premacos-readiness.md` for exact revision/commands and `macos-test-packet.md` for host experiments. Desktop compatibility, independent reviewer execution under Desktop/Pro, companion write recovery, onboarding integration and private-quality acceptance remain unverified. The existing 24 private-fixture cases remain unresolved; public-CI skips do not waive them. Original product/audit tasks remain governed by the audit disposition and approved plan.
