# Production review surface

Mode: Operate. The approved student workflow, source evidence and actions in
2026-11-18-student-workflows-design.md are the product authority. Platform: a
self-contained MCP App using the already tested ext-apps2.0.4 bridge. Mac embedding
acceptance remains separate. No new server, external fonts, imagery or endpoints.

## Direction contract

THESIS: let a student compare one proposal with its exact source and existing
coverage, then make a reversible local decision before exact authorization.
OWN-WORLD: inherit the existing compatibility surface's restrained green action,
light reading surface, system font, native labelled controls and visible focus.
STORY: read action and card text, inspect cited passage and existing candidates,
keep/exclude/edit/defer/choose a match; approve only the current validated batch.
FIRST VIEWPORT: run title and saved state, current item/action, text alongside
source at desktop width; stacked reading order at phone width; explicit save and
quality/approval status follow the item. Existing-note changes are separately named.
FORM: paged document/editor; seed: none (pinned), "source-linked production review
UI, stale-session protection, affected quality reruns and accessibility".
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish
review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

No interview or visual-choice restart: the user's approved specification and
existing bridge/probe establish this surface's purpose, constraints and execution
method. No shipping raster assets are introduced. Screenshots are test evidence.
