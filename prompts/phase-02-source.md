# Phase 2: Source pipeline (`cards extract`, `cards source`, `cards target`)

> Paste into a **new T3 thread** (GPT-6.1 Sol · High · Auto) on branch `anki-v2`. Self-contained.

## Not in this phase

- No drafting, checking, rendering or occlusion building. You export figures and OCR their labels for the map, but don't build masks.
- Don't call Anki, and don't create decks. `target` only *names* the deck and says whether it must be created.
- Don't read lecture PDFs as images to "check" your work. Compare against the extracted text and the tests.

## Goal

From a lecture PDF (or a text file), produce, with zero model tokens:
- per-slide text, figures with OCR'd labels, objectives, flags
- a one-line-per-slide map
- a slice reader
- the flat deck name taken from slide 1

## Requirements in scope

- **FR-3**: extract
- **FR-4**: map
- **FR-5**: slice reader
- **FR-6**: cache
- **FR-7**: text sources
- **FR-1**: deck from slide 1 (ADR-8)

2. `src/cards/source.py` and `cards source`.
3. `src/cards/target.py` and `cards target` (port of `deck_name.py` plus the flat-deck rule).
4. Small synthetic PDFs for the reading-order, image-only and no-objectives tests are generated by the tests themselves. The real L006/L007 PDFs come from `private_fixture()`.

Write the Phase 2 contract tests first (`tests/contract/test_p2_source.py`, `test_p2_target.py`), show red, then implement.
